12. THE ROBOT MATCHING MODEL

Robot selection can combine several dimensions.

Task Requirements
        ↓
Capability Match
        ↓
Performance Match
        ↓
Behavior Match
        ↓
Personality Match
        ↓
Safety Compatibility
        ↓
Suitable Robot

This creates a structured foundation for future robot discovery.

13. THE ADAPTATION MODEL

Behavior can evolve through permitted feedback.

Interaction
     ↓
Observation
     ↓
Feedback
     ↓
Evaluation
     ↓
Learned Preference
     ↓
Future Behavior

The architecture must distinguish:

Core Personality

from:

Learned Preference

Example:

Core Personality:
Patient

Learned Preference:
User prefers slower speech

Current Behavior:
Slower speech with that user

 ↓
